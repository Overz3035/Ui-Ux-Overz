# Drift and Boundary Reference

Load when execution starts changing the aim, scope, frame, or decision authority, or when the work may be hard to reverse.

## One-Way Door Check

If the work locks in architecture, public API, data model, security posture, external commitments, or hard-to-reverse workflow, run `/dissent` before proceeding.

## Execution Boundary

Execution means implementing the selected approach. Pause when:
- implementation quietly changes the aim or frame;
- decision authority is ambiguous;
- dissent is skipped before a hard-to-reverse move;
- confidence falls while artifacts keep accumulating.

Ordinary continuation does not need permission.

## Drift Signals

- Scope expands beyond the declared task.
- You touch files not required by the plan.
- "While I'm here" starts driving work.
- The approach reverses direction.
- You protect code because you invested in it.
- The finish line keeps moving.

## Drift Response

- **Aligned:** continue.
- **Minor drift:** note and refocus.
- **Significant drift:** pause; refocus, confirm scope change, or salvage.
- **Lost:** invoke `/salvage` immediately.
