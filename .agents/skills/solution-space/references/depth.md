# Solution-Space Depth Reference

Load only when options are high-stakes, too similar, or the recommendation feels overconfident.

## Escalation Ladder

Use the lowest level that plausibly solves the problem.

1. **Band-Aid:** patch the symptom. Acceptable under deadline pressure; toxic as habit.
2. **Local Optimum:** improve within current assumptions. Cleaner, same shape.
3. **Reframe:** question the problem statement. Different story, different options.
4. **Redesign:** change the system so the problem dissolves.

## Candidate Generation

Generate before evaluating:
- Include the obvious option.
- Include status quo when real.
- Include at least one option above your instinct on the ladder.
- Maximize variance early; collapse later.

## Decision-Changing Evaluation

Before scoring, name:
- Decision criteria: what matters most and how options will be compared.
- Critical assumptions: premises the recommendation depends on.
- Early eliminators: constraints that make an option non-viable.

For each candidate, answer only what changes the recommendation:
- Does it solve the stated problem?
- What frame does it assume?
- What is the main implementation or maintenance cost?
- What second-order problem or future option does it create?
- Which critical assumption would invalidate it if false?

## Interpretive Variety

Before recommending, ensure the option set is not one frame in costumes:
- Which option assumes the current frame?
- Which option tests or challenges it?
- What would failure teach?

If all candidates share the same hidden frame, generate one different-frame candidate or return to `/problem-statement`.
