# Salvage Extraction Reference

Load only when a salvage needs deeper learning extraction than the core report.

Extract what is present; do not pad empty categories.

## Categories

1. **Model shifts:** what assumption changed?
2. **Frame shifts:** what story stopped explaining reality?
3. **Guardrails:** what constraint was discovered the hard way?
4. **Missing context:** what should have been found or asked earlier?
5. **Ownership / coordination:** what authority, owner, handoff, review, dissent, or verification boundary blurred?
6. **Local practices:** what situated metis should carry forward?
7. **Reusable fragments:** what code, pattern, or partial approach is worth keeping?

## Persistence

Persist metis, not noise. Generic advice that adds no local leverage should be omitted. If repeated salvages surface the same lesson, run `/distill`; the corpus has knowledge but it is not being consulted.

If OH/RNA tools are available, check for existing related metis/guardrails before creating new entries to avoid duplicates.
