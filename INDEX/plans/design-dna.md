# Design DNA — final-check

> Generated by UIUX ENGINE. Unique to this project: direction,
> palette, type, spacing and motion were derived from the project
> requirements — not copied from a template.

## Product Identity
- **Direction:** Precision Editorial — Typography-led, generous whitespace, restrained palette with one decisive accent. Confidence through clarity.
- **Alternatives considered:** Industrial Control, Warm Humanist (rejected on fit)

## Audience & Industry
- Recorded in .uiux/context.json; tune the direction if it changes.

## Visual Direction
- Density: **spacious**; motion: **restrained**; radius family: **sharp**
- Layout: navigation **centered-topbar**, grid **asymmetric 2:1**, hero **media-led**
- Imagery: duotone

## Color Strategy
- Strategy: **duotone** (light surface system)

| Token | Value | Role |
|---|---|---|
| background | `#f4f6f5` | page base |
| surface | `#e9ecea` | cards, panels |
| text | `#142e1e` | body copy (WCAG-checked) |
| muted | `#142e1e` | secondary text (4.5:1) |
| border | `#dee3e0` | hairlines, dividers |
| accent | `#1b984a` | primary actions, focus |
| accent-2 | `#da2f99` | secondary emphasis |
| on-accent | `#0a0000` | text on accent (4.5:1) |
| success | `#347f4f` | positive states |
| warning | `#b1863b` | caution states |
| danger | `#ca2b2b` | destructive states |

## Typography
- Display: **Instrument Serif** / Body: **Geist** / Mono: JetBrains Mono
- Type scale ratio: 1.25 (modular scale, clamp() for fluid)
- Numerals: tabular-nums in data contexts

## Spacing & Density
- Base unit: 8px; scale: [8, 16, 24, 32, 48, 64, 96, 128, 160, 192]
- Row height 56px, card padding 24px, grid gap 24px

## Motion
- Fast 120ms / base 200ms / slow 320ms, stagger 30ms
- Signature easing: `cubic-bezier(0.2, 0, 0, 1)`
- Intensity: low — motion confirms, never decorates

## Accessibility Contract
- Body text ≥ 4.5:1, large text ≥ 3.0:1, UI ≥ 3.0:1
- Touch targets ≥ 44px; visible focus on every interactive element
- prefers-reduced-motion: every choreographed effect has a static equivalent

## Things to Avoid
- Reaching for a template: this DNA defines the decisions, not a page.
- Decorative motion on task surfaces; it costs users time and battery.
- Low-contrast greys on tinted backgrounds (WCAG is a floor, not a goal).
- Adding a second accent colour without retiring the first.
