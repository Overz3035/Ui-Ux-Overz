# KNOWLEDGE — Taste & Visual Quality

Replaces the external "taste" skill when it is not installed. Read when
making or judging visual decisions.

## 1. What "taste" means operationally

Taste is a set of refusals. Quality emerges from consistently declining:

- symmetry without reason (asymmetry needs a job: emphasis, flow, surprise)
- a second accent color while the first still has work
- motion that repeats what layout already communicates
- decoration that survives the question "what does the user gain?"
- equal-weight elements in a row that should have hierarchy
- centering as the default instead of a decision

## 2. Visual hierarchy levers (in order of strength)

1. **Scale** — one dominant element per view; everything else yields.
2. **Weight/contrast** — reserve the heaviest weight for the fewest words.
3. **Color** — accent draws the eye once; a second use dilutes the first.
4. **Space** — isolation is emphasis; crowded importance is no importance.
5. **Motion** — the only moving element is the important one.

If two things compete, neither wins. Re-rank, don't equalize.

## 3. Color relationships

- Build on one base temperature (warm or cool), not both at full strength.
- Accent sits ~150–210° from a muted base for emphasis without vibration.
- Neutrals carry the hue of the brand (a hint of it), never pure grey.
- Status colors (success/warning/danger) are reserved vocabulary — accent
  must not look like any of them.
- Text pairs are WCAG-checked before they are pretty-checked.

## 4. Typography judgment

- Two families maximum; the display face may be loud, the body face never.
- Line length 45–75 chars; measure beats font size for readability.
- Display faces carry identity at large sizes only; at 14 px they crumble.
- Numeric interfaces use tabular numerals — always.

## 5. Composition

- One grid, broken deliberately: a single offset element energizes a page.
- Diagonal flow reads as motion; horizontal bands read as calm; use intent.
- Whitespace is a material — allocate it like a budget per region.
- Depth (layering, shadow, blur) must reflect real z-order, not decorate.

## 6. Avoiding the generic AI look

Generic AI UI: purple gradient hero, 3 floating cards, rounded-2xl glass,
one stock illustration, Inter everywhere, parallax blobs.

Counter-moves (choose per project — never all):
- a typographic hero with no illustration
- a single accent used exactly three times per page
- one deliberately sharp corner family against the expected softness
- data or proof placed above the fold instead of adjectives
- an asymmetric grid with a visible logic
- imagery style from the DNA's imagery family, not "abstract gradient"

## 7. Self-review questions

1. What is the ONE action this view exists for? Is it the most prominent?
2. Remove any element — does the page lose more than it gains?
3. Does anything move? Must it?
4. Would a competitor page be distinguishable from this in a screenshot
   without the logo? (If not, re-run the DNA, don't decorate.)
