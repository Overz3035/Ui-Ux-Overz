# UIUX Design Pipeline

Skills are vendored in `.agents/skills/` (installed via `npx uiux-overz init`).

1. Read `.uiux/design-dna.md` (visual law). If missing, draft it first from the
   brief and get approval — direction, palette, type, spacing, motion, a11y.
2. Route methodology skills (max 3): animate / cast / paint /
   design-taste-frontend / frontend-design / motion-design /
   web-design-guidelines. Cite the DNA on every decision.
3. Implement, then run the `design-audit` checklist — fix all Critical
   findings before finishing.
